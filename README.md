# Brainrot Clicker 🧠

**Brainrot Clicker** is a parody incremental game where you try to generate as much dopamine as possible.

## UI Inspiration and Credits

### 1. Inspiration from Planet Clicker

**Link to my peer's project:** <https://github.com/inyoo403/D1.a>

- The layout of my UI was largely inspired by Planet Clicker, where the title, counter stats, and main button are grouped in a panel on the left, while the shop upgrades are displayed on a panel to the right.

- The concept of a giant, visually obvious main button was also inspired by Planet Clicker.

### 2. Inspiration from Frog Clicker

**Link to my peer's project:** <https://github.com/mgembree/cmpm-121-f25-mattembree>

- The fun, bouncy title was inspired directly from Frog Clicker.
